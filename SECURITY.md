# Security Policy

## Supported Versions

| Version | Supported | Maintenance Level |
|---|---|---|
| 1.0.x (main branch) | Yes | Active security patches and data integrity fixes |
| < 1.0.0 | No | End of Life |

---

## Reporting a Vulnerability

If you identify a security issue, sensitive information disclosure, or calculation manipulation vulnerability:
- Email maintainer: `izuki99999@gmail.com` with subject `[SECURITY] PTN Keketatan Platform Report`.
- Provide clear reproduction steps, affected data assets, and an impact assessment.
- Do not open public GitHub issues for security vulnerabilities before they have been reviewed.
- Initial triage and acknowledgment will be provided within 48 hours.
