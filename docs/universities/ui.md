# Profil Selektivitas: Universitas Indonesia (UI)

Universitas Indonesia (UI) merupakan perguruan tinggi negeri tertua dan terkemuka di Indonesia, berpusat di Kampus Depok (Jawa Barat) dan Kampus Salemba (Jakarta Pusat). UI secara konsisten menduduki peringkat teratas nasional dan masuk ke dalam kelompok universitas dengan rasio selektivitas paling ketat di seluruh Indonesia.

---

## 1. Ringkasan Institusi

- **Kode Institusi:** UI
- **Peringkat Akreditasi Institusi:** Unggul (BAN-PT)
- **Status Kelembagaan:** PTN Badan Hukum (PTN-BH)
- **Lokasi Kampus:** Kampus Depok (Utama) dan Kampus Salemba (Kesehatan & Multidisiplin)
- **Portal SPMB:** https://penerimaan.ui.ac.id

## 3. Dinamika Jalur Masuk Mandiri (SIMAK UI)

Selain jalur seleksi nasional (SNBP dan SNBT), UI menyelenggarakan seleksi mandiri terintegrasi melalui **SIMAK UI** yang mengalokasikan kuota hingga 50% daya tampung untuk kelas Sarjana Reguler, Sarjana Non-Gelar (Kelas Khusus Internasional / KKI), dan Program Sarjana Terapan Vokasi.
